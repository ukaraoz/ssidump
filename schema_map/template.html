SSI Database Schemas

Five schemas and 17,505 tables. Almost all of them are narrow time-series tables, one per sensor variable. The relational model that describes sites, instruments, samples and genomes lives in odmx.

How the schemas fit together

Raw source tables in feeder are split into one table per variable in datastreams. The odmx catalog points to both by table name, not by foreign key.

datastreams: one table per variable

All 15,747 tables use one of two column layouts. Each odmx.sampling_feature_timeseries_datastreams row names its table in datastream_tablename. The 8,784 _view versions read the matching feeder column directly and apply a multiplier and offset.
